# ReviewNFC Go

Native iOS application built with SwiftUI and Xcode.

## Build

1. Clone this repository.
2. Open `reviewNfcGo.xcodeproj` in Xcode.
3. Provide your own local configuration in `reviewNfcGo/LocalConfig.swift` as required by the project. This file is excluded from version control.
4. Select an iOS simulator or a development device and build the application.

## Security and privacy before distribution

- Do not commit API secrets, signing certificates, provisioning profiles, passwords, or user data.
- Verify that previously committed files and Git history contain no credentials before distributing source code.
- Check all third-party service terms, privacy disclosures, permission descriptions and account-deletion requirements before submitting to Apple.
- Review the NFC, location, notification and Live Activity features on real devices.

## App Store publication

This is an Xcode/SwiftUI project, **not a Day project**. App Fair currently requires a conventional Day application and a specific organization/repository structure; merely publishing this source repository does not make it eligible. See [App Fair developer FAQ](https://appfair.org/docs/faq/) and [getting started](https://appfair.org/docs/getting-started/).

A standard Apple App Store submission requires an eligible Apple Developer Program account or an authorized publisher willing to submit the application through its own account.
